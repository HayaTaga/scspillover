# README: Replication Package for "Identification and Bayesian Inference for Synthetic Control Methods with Spillover Effects"

**Authors:** Shosei Sakaguchi and Hayato Tagawa  
**Date:** November 2025  
**Manuscript Number:** MS 36888  

## Overview

This package reproduces every simulation study, the two empirical applications (California tobacco tax; Sudan/South Sudan split), and the Bayesian diagnostics (Joint Distribution Test, Prior Predictive Analysis, sensitivity, and convergence checks) reported in the paper and appendix. All analysis is written in **R**, while the computational bottlenecks are implemented in **C++** via **Rcpp** (see `src/20_mcmc.cpp`). Every dataset and script needed for replication is bundled under this `replication_package/` directory, primarily as R Markdown scripts in `Rmarkdown/`.

## Data Availability and Provenance Statements

### Statement about Rights

All data included here are sourced from publicly available repositories and redistributed under their respective terms of use. The authors have permission to use and share the processed data objects contained in this package.

### Details on Each Data Source

1. **California Tobacco Tax Data**
   * **Source:** Abadie et al. (2010) and Scott Cunningham (2021) mixtape data.
   * **File:** `data/california_smoking.rda`
   * **Contents:** `panel_df` (state-level annual per-capita cigarette consumption), `w` (spillover vector for California’s neighbors), `W` (row-normalized adjacency matrix excluding California).
   * **Raw provenance:** Generated by `R/61_processed_california.R` from `data/raw/smoking.dta` and `data/raw/tl_2024_us_state/`. Intermediate CSVs are stored under `data/processed/tobacco/`.

2. **African Economic & Trade Data (Sudan Application)**
   * **Source:** World Bank World Development Indicators, IMF Direction of Trade Statistics, and supplemental FRED series.
   * **File:** `data/sudan_secession.rda`
   * **Contents:** `panel_df` (African country panel of GDP per capita and macro covariates), `w` (trade-volume spillover vector), `W` (trade-weight matrix).
   * **Raw provenance:** Produced by `R/62_processed_sudan.R` from `data/raw/P_Data_Extract_From_World_Development_Indicators/` and `data/raw/IMF_trade.csv`. Derived CSVs live in `data/processed/Sudan/`.

3. **Simulation Inputs**
   * **Source:** Fully synthetic.
   * **Files:** `inst/tables/mc_result/*.csv` and related summaries, regenerated by `R/30_simulation_.R`.

## Computational Requirements

### Software

* **R** ≥ 4.2.0
* **C++ compiler** (Rtools 4.3, Xcode Command Line Tools, or g++) to build `src/20_mcmc.cpp` and `src/40_geweke_latest.cpp` via Rcpp.

Key R packages (matching `DESCRIPTION`):
* `Rcpp`, `RcppArmadillo`, `Matrix`, `progress`
* `dplyr`, `tidyr`, `readr`, `ggplot2`, `patchwork`
* `rmarkdown`, `knitr`, `kableExtra`, `ggpattern`

### Memory & Runtime

* **Memory:** ≥ 8 GB recommended
* **Approximate runtimes (Apple M1, 16 GB)**
  * `vignette-california.Rmd`: 30–60 minutes
  * `vignette-sudan.Rmd`: 30–60 minutes
  * `vignette-simulation.Rmd`: 2–4 hours for the full grid (reduce `sim_grid` or `sims_per` for quicker smoke tests)
  * `vignette-geweke.Rmd`: 10–20 minutes

## Description of Codebase

* **R/00_constructor.R, R/00_generics.R**: S3 class definitions and constructors.
* **R/01_utils.R – R/04_utils_*.R**: Data preparation, plotting, and diagnostic utilities.
* **R/10_sc_spillover.R**: Core `sc_spillover()` two-step estimator and posterior summaries.
* **R/21_mcmc_alpha.R, R/22_mcmc_sar.R**: Horseshoe prior sampling and SAR MCMC kernels.
* **R/30_simulation_.R**: Monte Carlo study framework.
* **R/40_geweke_latest.R, R/41_robustness_check.R**: Geweke/JDT routines and robustness checks.
* **R/50_plots_paper.R**: Publication-quality plotting helpers.
* **R/61_processed_california.R, R/62_processed_sudan.R**: Data preprocessing scripts that recreate `.rda` files via `usethis::use_data()`.
* **src/20_mcmc.cpp, src/40_geweke_latest.cpp**: High-performance samplers exported through Rcpp.
* **Rmarkdown/**: R Markdown replication scripts (`vignette-*.Rmd`).
* **inst/figures**, **inst/tables**: Saved figures and table outputs referenced in the manuscript.

## Instructions to Replicators

1. **Unpack the archive:** Extract the ZIP and set the working directory to the `replication_package/` folder (the directory containing this README).
2. **Install dependencies:**
   ```r
   install.packages(c(
     "Matrix","progress","ggplot2","Rcpp","RcppArmadillo",
     "dplyr","tidyr","readr","patchwork","rmarkdown","kableExtra","ggpattern"
   ))
   ```
3. **Load the source package:**
   ```r
   setwd("/path/to/replication_package")
   devtools::load_all(".")
   ```
4. **Reproduce main-text figures/tables:**
   ```r
   rmarkdown::render("Rmarkdown/vignette-california.Rmd")
   rmarkdown::render("Rmarkdown/vignette-sudan.Rmd")
   ```
   Outputs are written to `inst/figures/` and `inst/tables/`.
5. **Reproduce simulation study:**
   ```r
   rmarkdown::render("Rmarkdown/vignette-simulation.Rmd")
   ```
   Adjust `sim_grid`, `sims_per`, and `M` at the top of the vignette for quicker dry runs.
6. **Appendix diagnostics (JDT, PPA, sensitivity):**
   ```r
   rmarkdown::render("Rmarkdown/vignette-geweke.Rmd")
   ```
7. **Regenerating `.rda` data:** Run `source("R/61_processed_california.R")` and/or `source("R/62_processed_sudan.R")` to rebuild `data/*.rda`. External API keys (e.g., FRED) may be required.
